# 猫手册 · PawBook

手机上的养猫小本子：**档案 / 日程提醒 / 忌讳清单 / 装备清单 / 摄像头入口**。
纯前端 PWA，不用服务器、不用账号、数据只存在本机。

> 线上地址：<https://imousem.github.io/pawbook/>

## 能做什么

### 1. 猫档案（比第一版补齐了常见项）

| 分类 | 字段 |
|---|---|
| 基本 | 名字、小名、品种、花色、性别、生日、到家日 |
| 身体 | 体重（曲线 + 目标区间 + 滑动平均 + 按月明细）、芯片号、绝育状态与日期 |
| 生活 | 猫粮、猫砂、常去医院、医院电话、保险单号 |
| 健康 | 过敏/忌口、既往病史、备注、疫苗记录（可多条，自动算下次） |
| 照片 | 拍照或选图，自动压到 640px 存本地 |

**体重面板**：大字显示当前体重和涨跌；曲线带目标区间（手填，或按品种+月龄取参考值）、虚线滑动平均（最近最多 7 次）；下面按月折叠列出全部记录，可逐条删除。

### 2. 日程（第二栏，已不只驱虫）
新建猫时会自动生成 9 条默认日程，**全部可改可删，也能自定义**：

| 事项 | 默认周期 |
|---|---|
| 体内驱虫 | 90 天 |
| 体外驱虫 | 30 天 |
| 疫苗加强 | 365 天 |
| 称体重 | 30 天 |
| 剪指甲 | 21 天 |
| 洗耳朵 | 14 天 |
| 梳毛 | 3 天 |
| 换猫砂 | 14 天 |
| 体检 | 365 天 |

- **自定义事项**：名称、图标、每几天、提前几天提醒、上次完成日期、备注；
- 可以挂在某只猫身上，也可以挂「全部猫」；
- 状态三色：正常（绿）/ 临近（黄）/ 逾期（红），另有「未记录」；
- 筛选：全部 / 已逾期 / 7 天内 / 未记录；
- **导出 .ics**：一键把未来一年日程导进手机日历，系统级提醒，零成本、不用服务器。

### 3. 忌讳（原来那栏「百科」换掉了）

按「致命 / 高风险 / 注意」三级，列 38 条具体禁忌，分**吃的、植物、家里、药与化学、护理、急诊信号**六类，每条写清「为什么危险 + 该怎么做」。

- 顶部会读档案里的生日，算出最小那只猫的月龄，**标 ★ 的是这个月龄风险最高的几项**；
- 支持分类筛选和搜索（搜「百合」「线」「蚊香」「尿闭」都行）。

### 4. 装备（第四个 tab）

买什么 / 不用买，25 条分三类：**必买**（8 条）、**推荐**（10 条）、**别买**（7 条，避坑）。

- 每条带常见价格区间，可勾选「已买」、填「实付」；
- 顶部实时统计：必买完成度、参考预算、已花多少；
- 可以「＋ 加一件自己的」自定义条目，跟着存进本地。

### 5. 摄像头
填一个手机浏览器能打开的画面地址（RTSP 需先用 go2rtc / MediaMTX 转 WebRTC/HLS）。

## 怎么用

**直接访问**：<https://imousem.github.io/pawbook/>

**装成图标**（推荐，装完有独立图标、全屏、离线可用）：

- 安卓 Chrome：右上角 ⋮ → 安装应用
- iPhone Safari：分享 → 添加到主屏幕
- 微信里打不开：点右上角「⋯ → 在浏览器打开」

**本地开发**：

```powershell
cd C:\Users\sasns\.dsh\profiles\desktop\deliverables\pawbook
python -m http.server 8765
# 打开 http://127.0.0.1:8765
```

## 数据

- 存在浏览器 `localStorage`，键名 `pawbook.v2`（旧版 `pawbook.v1` 会自动迁移）；
- 每人手机各自一份，互不影响；
- 换手机/清缓存前：档案页底部「导出 JSON」，「导入 JSON」恢复。

## 文件

```
pawbook/
├── index.html            全部界面与逻辑（单文件）
├── manifest.webmanifest  PWA 清单
├── sw.js                 离线缓存（改了 index.html 记得 VERSION +1）
├── icon.svg              图标
└── README.md             本文件
```

## 已知限制

- 提醒是**打开 App 才计算**；要真正的后台推送，需要一台服务器（免费额度方案见 README 末尾），或者用「导出 .ics」走手机日历。
- 数据不跨设备同步。
- 照片存 localStorage，单张压到 ~50KB，几十张没问题。

## 如果要后台推送（需要服务器，但有免费额度）

| 方案 | 免费额度 | 适合 |
|---|---|---|
| Cloudflare Workers + Web Push | 10 万请求/天 | 想真正推送，代码稍多 |
| Vercel / Netlify Functions | 免费 Hobby | 同上 |
| Bark（iOS）/ Server酱 | 免费 | 只推给自己，最简单 |
| 手机日历（.ics） | 完全免费 | **推荐**，零维护 |
