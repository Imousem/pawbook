# 猫手册 · PawBook

手机上的养猫小本子：**建档 / 驱虫提醒 / 养猫百科 / 摄像头入口**。
纯前端 PWA，不用服务器、不用账号、数据只存在本机。

## 怎么用（三步）

1. **起一个本地服务**（浏览器不允许 `file://` 用 Service Worker，所以要走 http）

   ```powershell
   cd C:\Users\sasns\.dsh\profiles\desktop\deliverables\pawbook
   python -m http.server 8765
   ```

   然后浏览器打开 <http://127.0.0.1:8765>

2. **装到手机上**
   - 手机和电脑连同一个 Wi-Fi，用电脑局域网 IP 访问：`http://<电脑IP>:8765`
   - iOS Safari：分享 → 添加到主屏幕
   - Android Chrome：右上角菜单 → 安装应用 / 添加到主屏幕

   装好之后有独立图标、全屏运行，断网也能打开（Service Worker 缓存）。

3. **建档**：点「＋ 添加一只猫」，填名字/品种/生日/体重，拍照或选照片（自动压到 640px）。
   之后在「驱虫」页点「今天做了」，就会按周期自动算下一次。

## 功能说明

| 模块 | 能做什么 |
|---|---|
| 档案 | 名字、品种、性别、生日、体重、备注、照片；卡片上直接显示两个驱虫状态 |
| 驱虫 | 体内默认 90 天、体外默认 30 天；提前 3 天转黄，逾期转红；一键「今天做了」 |
| 百科 | 14 条高频问题（驱虫、换粮、吐毛球、软便、应激、尿闭、绝育、疫苗、饮水、剪指甲、选粮、家中危险物、多猫相处），支持搜索 |
| 摄像头 | 填一个网页能打开的地址（HLS / WebRTC / 厂商网页版），点按钮新窗口打开 |
| 备份 | 导出 / 导入 JSON，换手机或清缓存前记得导 |

数据存在浏览器 `localStorage`，键名 `pawbook.v1`。

## 摄像头这块的现实情况

- 浏览器**不能直接播 RTSP**，需要中间转一层：
  - 有 NAS / 常开电脑：装 **go2rtc** 或 **MediaMTX**，把 RTSP 转成 WebRTC/HLS，把转好的网页地址填进来；
  - 小米/萤石/TP-LINK 这类：大多有「网页版预览」地址，直接填；
  - 只想看门口：填厂商 App 的分享链接也行（会跳到 App）。
- 想做真正内嵌的实时画面，下一步可以加一段 `<video>` + WebRTC 播放器，前端已预留位置。

## 已知限制

- 提醒是**打开 App 才计算**，没有后台推送（要推送得接服务器 + 通知权限，属于下一步）。
- 数据不跨设备同步；多设备用「导出/导入 JSON」手动搬。
- 照片存在 localStorage，单张压到 ~50KB，几十张没问题；拍视频不行。
